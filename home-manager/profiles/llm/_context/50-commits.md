# Commit Rules

- Unless instructed otherwise, commit completed changes according to these rules.
- Follow the repository's commit message style, using recent history as a guide
  for the subject, body, and formatting.
- Set both the author and committer to `Nano <nano@linyinfeng.com>` for every
  commit, and include
  `Co-authored-by: Lin Yinfeng <lin.yinfeng@outlook.com>`.
  Use `git -c user.name=Nano -c user.email=nano@linyinfeng.com commit
--trailer 'Co-authored-by: Lin Yinfeng <lin.yinfeng@outlook.com>' -m 'subject'`.
  Keep these identity settings scoped to the command; do not change Git config.
